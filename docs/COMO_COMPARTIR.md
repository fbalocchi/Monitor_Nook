# Compartir el proyecto

Este paquete corresponde a la versión pública 1.1.3 y está preparado para un
repositorio nuevo. No incluye una carpeta .git ni historial de versiones.

La ubicación inicial del clima es Madrid, España, como ejemplo editable desde
Ajustes. La zona del calendario sigue siendo America/Santiago.

El código, los instaladores y el APK se distribuyen directamente en las carpetas
del repositorio. GitHub permite descargar el proyecto completo mediante
Code → Download ZIP. La app instalada funciona con el lector y Wi-Fi.

La copia pública no contiene claves privadas de firma, datos del lector ni el
enlace de Calendar de su autor. Conserva tu clave privada fuera del repositorio
para futuras actualizaciones de la app.

Al publicar fotos del panel, revisa qué nombres y eventos familiares aparecen.
